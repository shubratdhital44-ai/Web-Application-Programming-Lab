This repository contains six labs designed to build a strong foundation in both frontend and backend development through a step-by-step approach. It starts with basic web development concepts and gradually moves toward building full-stack applications with authentication and database integration. Each lab focuses on a specific concept, making the overall learning process structured and easy to follow.

The first lab is a simple portfolio website created using HTML, CSS, and JavaScript. It includes a calendar feature, which helps demonstrate basic DOM manipulation and interactive UI design. The second lab introduces core JavaScript concepts such as variable declarations using var, let, and const, along with functions, arrow functions, objects, and modern array methods like map and filter. It also covers the use of spread operators, giving a clear understanding of essential JavaScript features.

The third lab shifts to React and focuses on building login and registration forms. It uses custom input components and React state to manage form data and user interaction. The fourth lab continues with React by implementing a Todo application that supports CRUD operations. It shows how to create, update, delete, and display tasks using state management, helping to understand how dynamic user interfaces work.

The fifth lab introduces backend development using FastAPI. It implements user authentication with login and registration features while maintaining a proper project structure that includes controllers, database connections, models, migrations, and routes. The final lab builds on this by connecting todos with authenticated users. It uses ORM and database migrations to ensure that each user can access only their own data, completing the full-stack workflow.

Overall, this repository demonstrates a clear progression from basic frontend development to a complete backend system, making it useful for understanding how different parts of a web application work together.
